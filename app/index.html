Conectar ao sistema

O app precisa de uma chave do GitHub para aprovar os posts. Ela fica salva só neste celular.

  1. Abra criar chave no GitHub.
  2. Nome: app-aprovacao. Validade: a maior possível.
  3. Em Repository access, escolha Only select repositories e marque jn-marketing.
  4. Em Permissions → Contents, escolha Read and write.
  5. Clique em Generate token, copie e cole abaixo.
